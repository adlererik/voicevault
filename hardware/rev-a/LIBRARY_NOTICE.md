# KiCad library attribution

The files in `VoiceVault.pretty/` are the unmodified used footprints from the official KiCad footprint library installed with KiCad 10.0.8. Their upstream license is Creative Commons Attribution-ShareAlike 4.0 with the KiCad libraries exception. The exception permits use of these library elements in electronic designs without applying that license to the whole design. Preserve the upstream attribution and license when redistributing these library files.

[KiCad library licensing](https://www.kicad.org/libraries/license/) · [Upstream footprint library](https://gitlab.com/kicad/libraries/kicad-footprints) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

`VoiceVault.kicad_sym` and the carrier schematic are generated by `hardware/tools/create_project.py` for this project. The component symbols represent carrier interconnections. External module circuitry is documented through manufacturer references.
