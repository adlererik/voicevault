# VoiceVault C1 board renders

[Front](voicevault-front.png) · [Back](voicevault-back.png).

Native KiCad ray-traced previews of the actual local-repair-02 component positions, board outline and copper. Some missing or unavailable component models use approximate package bodies; see [provenance](render-provenance.json). These are CAD illustrations of an unfinished prototype, not photographs or mechanical/assembly qualification.

The render-only PCB and model directory reproduce the pictures without modifying the electrical project. Use the real [KiCad project](../../rev-c1/local-repair-02/voicevault-standalone-c1.kicad_pro) for engineering. Standard models are loaded from the installed KiCad 3D library; approximate bodies are supplied here.

Later [repair 03](../../rev-c1/local-repair-03/README.md) retains these component positions, with additional copper repairs. The pictures remain explicitly bound to repair 02.
